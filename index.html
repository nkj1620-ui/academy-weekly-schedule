GitHub Pages 게시 및 연동 안내
  1. 이 파일을 index.html 이름으로 GitHub 저장소에 올리세요.
  2. 저장소의 Settings → Pages → Deploy from a branch에서 main / (root)를 선택해 저장하세요.
  3. 게시된 페이지는 열 때와 ‘시트 새로고침’을 누를 때 구글 시트의 최신 데이터를 요청합니다. 접근 권한 또는 브라우저 제한으로 실패하면 표시 중인 데이터를 유지하고 상태를 안내합니다.
  4. 원본의 열 배치는 유지해 주세요. 왼쪽 C:H, 오른쪽 K:Q 시간표를 읽습니다. 열 배치가 바뀌면 연동 코드도 수정해야 합니다.
  5. 현재 파일에는 수업명과 수업에 적힌 이름이 포함됩니다. 공개 게시 시 방문자 누구나 볼 수 있으므로, 내부 전용 시간표라면 공개 게시 전에 접근 방식부터 결정하세요.
